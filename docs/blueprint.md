# **App Name**: Rayaan Advisory

## Core Features:

- Homepage Hero Section: Eye-catching hero section with key messaging and clear calls to action. The hero text will consist of a main and secondary headline with 2 call to action buttons.
- Services Overview Grid: Display key service cards including descriptions, icons, and links for more information.
- Contact Form Submission: Allow users to submit messages and store them securely in Firestore.
- Newsletter Subscription: Allow users to subscribe to a newsletter, storing email addresses in Firestore. The timestamp of subscription should also be stored.
- Appointment Booking: Enable users to book appointments, collecting necessary details and saving the information to Firestore. Confirmation is displayed upon successful form submission.
- Dynamic Statistics Counter: Implement counters that animate upon scrolling to showcase key stats, like advisory focus areas, service lines, etc.
- Blog content categorization and recommendation tool: Employ a tool that reads the blog content and uses it to add tags and identify the category of each blog, enabling it to generate relevant content recommendations for each user.

## Style Guidelines:

- Primary color: Deep Indigo (#262261) to convey professionalism and trust. The hex color was specified in the original prompt.
- Background color: Light Gray (#F7F8FC), as in the original prompt, provides a clean and modern feel.
- Accent color: Light Blue to highlight important elements and add a touch of premium elegance, according to the initial request.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable appearance, as suggested in the user request. Note: currently only Google Fonts are supported.
- Mobile-first approach with a clean, grid-based layout for optimal responsiveness and readability across devices.
- Use elegant, Islamic finance-themed icons in gold (#C8A24A) to represent services and key offerings.
- Subtle transitions and animations to enhance user experience without overwhelming the design. Examples: smooth scrolling and testimonial slider transitions.
